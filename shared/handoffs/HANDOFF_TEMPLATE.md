# 交接

## 已完成

填写已经完成的改动、产物、验证结果和关键决策。

## 变更文件

填写本次修改或生成的文件路径，并说明每类文件的作用。

## 证据

填写命令输出摘要、报告路径、自检结果或人工确认记录。

## 风险

填写仍未解决的问题、可能影响的范围和需要复核的点。

## 重试与回流

- attempt：填写当前尝试次数。
- 尝试计数：填写 `1/4` 到 `4/4`，第 `4+` 次写明已超出 4/4。
- 已用策略：填写自主执行、清理 working state、简化范围、换 Agent 实例 / 不同模型或回流。
- 是否进入回流：是 / 否。
- 回流目标：填写上游 Agent 或 Lead。
- 复核三问：如已进入回流，填写定义、可行、资源三问摘要。

## 下一步动作

填写接手者可以直接执行的下一步，包含命令、路径和判断标准。
