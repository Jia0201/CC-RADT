# 外部升级安全规则

## 执行边界

- CC-RADT 只能由 Harness 外的独立升级器进行跨版本升级；Lead、Agent、Hook 和工程内升级指令只提供操作说明，不在活动会话内执行覆盖。
- `tools/bin/ai-teams-upgrade.sh` 已退役。所有参数均不产生写入、快照或状态；`--help`/`-h` 返回说明和 0，其他调用返回说明和 2，不能将退出当作升级成功。
- 开始前由用户关闭目标项目的 Claude Code、Agent、Hook、观察台及其他写入任务，建立维护窗口；升级器锁不证明其他进程不会写入。无法确认环境、活动写入、权限或存储前提时停止，不自动强杀进程。
- 本规则是验收要求，不是跨平台验收证明。未经过原生 OS/文件系统验证的平台不得仅凭交叉编译就声明支持。

## 来源与授权

SHA-256 仅验证字节一致性，不证明官方来源。未签名 `upgrade-manifest.json` 默认只可只读预览；apply 前必须由真实用户在 UI/CLI 明确认可旧、新清单完整 SHA-256 指纹。不得默认勾选、只验证 buildId、让 Agent 代为认可，或通过通用“忽略签名”绕过。指纹授权绑定具体清单和计划，变更后重新确认。

生成器和 `--seal` 不签名，也不自动授权 apply。没有已配置发布公钥时不得显示“官方签名通过”；官方签名和密钥轮换由独立发布链路交付。即使用户已信任指纹，路径/哈希、兼容性、冲突及恢复门禁仍不可跳过。

已发布正式包、manifest、checksum、版本和标签不可重打或改写。旧包需要新清单时仅在包外生成 sidecar，标为未签名；不得从被用户修改的现用安装推导官方旧基线。源/运行分支及发布权限另按版本治理执行，生成清单不授权 push、tag 或 Release。

## 数据与配置

- 受管范围仅 `.claude/ai-teams/**`、扁平 `.claude/agents/*.md`/`.claude/rules/*.md`、明确安装配置与项目根 `.mcp.json`/`CLAUDE.md`。根业务 README、根 VERSION、业务源码不受管；系统 VERSION 是 `.claude/ai-teams/VERSION`。
- `memory/project/kb/shared` 必须按显式系统文件清单分类，未知默认 data；用户/项目运行资料、会话、记忆、自装扩展及提示词演进不得被包内模板覆盖。可信旧清单外文件不能自动认领为系统。
- 已核对的官方版本化 prompt、精确内置 Skill 静态文件、公开 MCP 指引配置、角色初始化 KB 应为 system/config，通过三方比较更新未改官方文件；不能把整个混合目录标为 data 而宣称功能已经更新。本地自进化与上游同时修改出不同内容时整次升级阻断，单方本地修改且上游未变时保留。
- 首版 generated 索引/图谱没有智能合并。本地与新版同时修改必须保守报冲突；仅本地改而上游未变时保留，不能声称“重建”后丢弃人工内容。
- settings、MCP 与注册表必须按可证明归属处理，未知或双方修改不能整表覆盖；不擅自扩大权限，不重建 `.claude/settings.local.json`。CLAUDE.md 无明确受管边界时不得猜测删除业务说明。
- 迁移仅允许受信清单明确声明的单文件 data 改名，在候选副本执行并核对字节守恒。无路线即阻断，不执行包提供的脚本、命令或下载。
- 路径越界、敏感文件、链接、特殊文件、大小写碰撞、不支持的权限/ACL、异常大小和不完整清单均应拒绝。报告不含业务正文、密钥和未脱敏配置。

## 事务与恢复

1. 预览只读，不在项目内建运行目录、日志、快照或更新 manifest。
2. apply 先验证并保留独立旧原件，在同卷项目外构建 candidate；备份不是可写硬链接。备份目录仅当前用户可访问，不自动清理，不上传。
3. 切换前重新检查文件集与哈希，变化即使计划失效。系统目录和外层配置属于同一事务，系统 VERSION 最后切换，不声称跨文件原子性。
4. 中断或失败必须进入需要恢复状态，阻止再次升级；恢复不能覆盖升级后新写入的数据。用户停止、取消、浏览器断开也不能伪报成功。
5. 首版只处理事务恢复，不提供会抹掉新数据的历史一键降级。原件留存不能代替异盘备份。

生成器/内核完整字段约束见开发工程 `updater/CONTRACT.md`；该源码文件不随 Harness payload 分发。用户入口见 [外部升级说明](../tools/commands/ai/upgrade-existing.md)。发布前由 QA 和 Security-Reviewer 复核数据守恒、故障注入、签名/指纹确认及原生平台证据。
