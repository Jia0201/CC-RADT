# QA Agent 知识库

QA 知识库保存测试设计、代码审查、回归验证、浏览器自动化和缺陷回流相关的稳定知识。

## 入口

- [00-index](./00-index.md)：细分知识库索引。
- [01-source-map](./01-source-map.md)：测试与审查来源。
- [02-engineering-rules](./02-engineering-rules.md)：验收和缺陷回流知识。
- [03-code-style](./03-code-style.md)：测试代码和验收报告格式。
- [04-review-checklist](./04-review-checklist.md)：代码审查清单。
- [05-do-not](./05-do-not.md)：禁止事项。

## 边界

QA 可以提出修复要求和风险结论，但不替代 Dev 写实现，不替代 Security-Reviewer 做权限/敏感文件最终判断。
