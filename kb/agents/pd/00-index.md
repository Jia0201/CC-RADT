# PD 知识库索引

PD 知识库保存需求澄清、产品目标、用户场景、范围边界、验收标准和需求文档结构相关的稳定知识。本知识库只记录可复用知识，不记录一次性任务过程。

## 文件

| 文件 | 用途 |
|---|---|
| [01-source-map](./01-source-map.md) | 产品需求、验收标准和工程内规范来源 |
| [02-engineering-rules](./02-engineering-rules.md) | 需求表达、范围、验收、风险和交接知识 |
| [03-code-style](./03-code-style.md) | PRD、用户故事、验收标准和待确认问题的写作风格 |
| [04-review-checklist](./04-review-checklist.md) | 可直接用于需求审查的清单 |
| [05-do-not](./05-do-not.md) | PD 需求知识禁区 |

## 使用规则

- 什么时候使用：用户意图、业务目标、用户角色、范围、非目标、验收标准或需求交接不清晰时。
- Codex 生成内容时要遵守：把用户价值、范围边界、验收条件和待确认问题写清楚；不得把技术实现、排期承诺或未验证假设伪装成需求事实。
