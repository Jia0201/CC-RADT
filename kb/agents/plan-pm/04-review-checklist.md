# Plan-PM 审查清单

## 目标与范围

- [ ] 计划是否能追溯到明确需求、目标或问题？
- [ ] 是否列出本次范围和不做的事项？
- [ ] 是否说明关键假设和待确认问题？

## 任务质量

- [ ] 每个任务是否有明确输入、输出和完成定义？
- [ ] 任务粒度是否足够小，能独立验收？
- [ ] 是否避免把研究、实现、验证和发布混成一个不可控任务？

## 依赖与并行

- [ ] 是否列出任务之间的前置条件和阻塞关系？
- [ ] 并行任务是否有清晰文件范围和交接点？
- [ ] 是否识别同文件修改、接口契约、数据迁移或文档同步风险？

## 验证与风险

- [ ] 每个任务是否有验证方式或替代审查方式？
- [ ] 高风险操作是否有安全审查或负责人确认入口？
- [ ] 是否说明无法验证时的残余风险？

## 交接

- [ ] 执行方是否能仅凭任务卡理解目标、范围和输出？
- [ ] QA 是否能从计划中提取验收对象和通过条件？
- [ ] Lead 是否能看出状态、阻塞和下一步决策点？
