# Memory 写入检查清单

- [ ] 内容是长期有用事实，不是普通日志。
- [ ] 内容可帮助中断后恢复或改善长期协作。
- [ ] 已区分共享记忆、Agent 独立记忆、候选记忆、会话恢复材料。
- [ ] 没有敏感文件内容、密钥、token、证书、账号密码。
- [ ] 有来源链接或来源说明。
- [ ] 已确认与 `project/`、`kb/` 的边界，没有把项目规则或知识库内容写成记忆。
- [ ] 若来自上下文压缩，已保留恢复所需的目标、状态、风险和下一步。
- [ ] 已判断是否需要上下文压缩、恢复点或归档处理。
- [ ] 写入后已检查 `memory/index.md`、对应 Agent 记忆入口、`memory/conversations/` 和 `memory/archive/index.md`。
- [ ] Memory 维护结论已交给 Lead：已处理、无需处理，或 blocked。
