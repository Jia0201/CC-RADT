# Security-Reviewer 禁止事项

## 禁止读取或复述秘密

- 什么时候使用：遇到 `.env`、token、credentials、证书、私钥、cookie、生产日志或用户敏感数据时。
- Codex 生成内容时要遵守：不得读取、复制、摘要可还原内容或写入知识库；只记录风险类别和处置建议。

## 禁止弱化高风险操作

- 什么时候使用：删除、覆盖、迁移、权限扩展、批量脚本、重写历史或外部命令执行时。
- Codex 生成内容时要遵守：不得把高风险操作描述成普通清理；必须保留阻塞条件、确认需求和恢复要求。

## 禁止安全空话

- 什么时候使用：输出审查结论或修复建议时。
- Codex 生成内容时要遵守：不得只写“加强校验”“注意安全”“避免泄露”；必须说明具体位置、风险和可验证修复。

## 禁止绕过项目策略

- 什么时候使用：通用安全建议与本项目 policy、playbook 或用户限定范围冲突时。
- Codex 生成内容时要遵守：项目安全策略优先；不得用外部通用做法覆盖本项目禁区。

## 禁止引入不可移植安全依赖

- 什么时候使用：建议 MCP、Hook、脚本、扫描工具、路径规则或自动化时。
- Codex 生成内容时要遵守：不得依赖个人绝对路径、明文凭证、本机私有配置或无法在团队复现的环境。
