# Dev-Frontend-Web 禁止事项

## 安全禁区

- 什么时候使用：任何前端代码、配置、构建和接口联调任务。
- Codex 生成代码时要遵守：不得把密钥、token、私有证书、服务端凭据、数据库连接串写入前端代码、构建产物或日志。

## API 契约禁区

- 什么时候使用：接口字段、请求参数、响应结构、错误码、鉴权流程变更任务。
- Codex 生成代码时要遵守：不得擅自改变 API 契约；必须同步类型、调用方、文档和测试。

## 错误处理禁区

- 什么时候使用：请求、表单提交、文件上传、权限校验、路由跳转任务。
- Codex 生成代码时要遵守：不得跳过错误处理；不得只 `console.log` 后吞掉错误；用户可见流程必须有反馈。

## 测试禁区

- 什么时候使用：新增组件、重构状态逻辑、改路由权限、改表单和关键流程时。
- Codex 生成代码时要遵守：不得声称已测试但没有运行或没有说明；不得生成无法执行的测试。

## 工程禁区

- 什么时候使用：引入依赖、修改构建、调整 lint、重构目录时。
- Codex 生成代码时要遵守：不得绕过 lint/typecheck；不得大面积关闭规则；不得引入与项目栈冲突的框架或过重依赖。

## 权限与审核禁区

- 什么时候使用：登录、权限、角色、菜单、路由守卫和前端安全相关任务。
- Codex 生成代码时要遵守：不得用前端隐藏替代后端授权；不得伪造权限通过；不得绕过产品或平台审核限制。
