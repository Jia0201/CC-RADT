# Lead Agent 知识库

Lead 知识库保存多 Agent 调度、任务路由、并行监督、回流仲裁和任务关闭检查相关的稳定知识。

## 入口

- [00-index](./00-index.md)：细分知识库索引。
- [01-source-map](./01-source-map.md)：Lead 优先读取来源。
- [02-engineering-rules](./02-engineering-rules.md)：调度、状态、回流、关闭规则知识。
- [03-code-style](./03-code-style.md)：任务单、执行方案、交接、汇报格式。
- [04-review-checklist](./04-review-checklist.md)：关闭任务检查清单。
- [05-do-not](./05-do-not.md)：禁止事项。

## 边界

Lead 不直接维护 `project/`、正式记忆和正式知识库；Lead 调度 Doc、Memory、Security-Reviewer 并在关闭前检查结论。
