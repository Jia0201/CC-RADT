# Lead 输出格式知识

## 什么时候使用

Lead 创建任务单、执行方案、交接、回流记录或最终汇报时使用。

## Codex 生成内容时要遵守什么

1. 任务单写清目标、范围、Owner、输入、输出、验证方式、禁止事项。
2. 执行方案写清阶段、文件范围、锁计划、并行 Agent、同步点、风险和验收。
3. 交接必须包含已完成、未完成、验证、风险、下一步和来源链接。
4. 最终汇报只说已完成、验证结果、未完成项和风险，不复制大段内部过程。
5. Markdown 内部引用优先使用 标准 Markdown 链接；需要脚本或用户定位时给出代码路径。
