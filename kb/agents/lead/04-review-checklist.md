# Lead 关闭检查清单

Lead 汇报前逐项检查：

- [ ] 用户最新需求已覆盖，没有回答旧任务残影。
- [ ] 非平凡任务已启用多 Agent，或用户明确要求单 Agent。
- [ ] `project/` 已由 Doc 处理或明确跳过。
- [ ] `memory/` 已由 Memory 判断是否需要写候选、压缩或恢复材料。
- [ ] Security-Reviewer 已检查敏感文件、删除、锁、MCP、命令风险。
- [ ] QA 已验收代码、文档或配置变更；无法验收时已说明原因。
- [ ] `shared/task-plan.md` 和 `shared/pipeline-status.md` 已更新到关闭状态。
- [ ] 锁已释放或记录为阻塞/过期并交给 Lead 仲裁。
- [ ] 文档关系图和索引已检查关键变更。
- [ ] 自检脚本已运行，失败项已修复或列为未完成。
