# Dev-Backend-Systems 禁止事项

## 契约禁区

- 什么时候使用：公共协议、ABI、DTO、枚举、接口、序列化结构。
- Codex 生成代码时要遵守：不得擅自改变公共契约；不得静默删除字段、改类型、改序列化格式。

## 内存与并发禁区

- 什么时候使用：C/C++ 内存、锁、线程、共享状态、Java 并发。
- Codex 生成代码时要遵守：不得生成可能泄漏、越界、悬垂、数据竞争、死锁的代码；不得为性能绕过安全。

## 构建禁区

- 什么时候使用：Maven、Gradle、CMake、Make、编译选项。
- Codex 生成代码时要遵守：不得写入本机绝对路径；不得随意升级依赖或语言版本；不得删除构建检查。

## 测试禁区

- 什么时候使用：测试失败、性能验证、静态检查。
- Codex 生成代码时要遵守：不得删除断言、屏蔽错误、降低检查强度或声称未运行的测试已通过。

## 安全禁区

- 什么时候使用：日志、配置、权限、系统调用。
- Codex 生成代码时要遵守：不得硬编码密钥；不得打印敏感信息；不得绕过权限和输入校验。
