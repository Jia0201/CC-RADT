# Skill 名称

## 用途

填写这个 Skill 要解决的问题，以及它比普通说明文档更适合复用的原因。

## 使用时机

填写触发关键词、适用任务、禁用场景和需要用户确认的情况。

## 流程

填写执行步骤、需要读取的文件、可能使用的工具、输出格式和验证方式。

## 安全边界

填写不得读取的敏感内容、不得执行的命令、不得写入的位置和回滚要求。
