# 沟通模板

## 用途

用于记录跨 Agent 沟通、决策、广播和任务同步信息。

## 所有者

Lead 负责维护，Plan-PM 和 Doc 可补充流程记录。

## 使用方式

复制 `template.md` 后填写沟通对象、背景、结论、待办、风险和后续负责人。

## 输出

生成共享沟通记录，可链接到 `shared/tasks/`、`shared/handoffs/` 或 `logs/task/`。
