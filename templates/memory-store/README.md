# 记忆存储模板

## 用途

用于把任务中验证过、长期稳定的事实写入正式记忆或候选记忆。

## 所有者

Memory Agent 负责维护，Lead 和 Doc 可提交候选。

## 使用方式

复制 `template.md` 后填写记忆内容、来源、置信度、适用范围、过期条件和刷新策略。

## 输出

生成 `memory/`、`memory/agents/` 或 `memory/candidates/` 下的记忆条目。
