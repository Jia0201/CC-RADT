# 项目 UI 与排版规则

- 当前项目的颜色、字体、间距、圆角、阴影、栅格、断点、组件和布局以 [ui-style](../../../project/ui-style.md) 为准。
- 修改页面前先定位现有相似页面和组件，不凭通用审美覆盖项目风格。
- 加载态、空态、错误态、禁用态、权限态、移动端遮挡和超长文本属于必查项。
- UI 事实不完整时，由前端 Agent 检查实际页面与样式入口，再由 Doc 更新 [ui-style](../../../project/ui-style.md)。
- 不把通用前端知识写入本文件；框架知识读取对应 Agent KB。
