# 项目前端语法与工程规范

- 技术栈和版本先查 [stack](../../../project/stack.md)，项目约定先查 [imported-rules](../../../project/imported-rules.md)。
- 组件命名、目录、状态管理、路由、请求封装、表单、权限、lint、格式化和测试必须沿用项目现有方式。
- 项目没有明确规则时，才使用对应 Agent KB 中的主流官方规范。
- 不自行升级框架、替换状态库、改变构建工具或修改 API 契约。
