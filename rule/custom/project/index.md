# 项目自建规则索引

这里登记目标项目接入后新增的项目级规则路由，例如某类目录、接口、UI、验证命令或平台规则需要稳定进入读取链。

## 适用场景

- 初始化扫描发现目标项目有明确开发规范，需要长期按需读取。
- UI、接口、数据库、权限、构建或测试规则发生稳定变化。
- 多次任务暴露同类字段、样式、路径或验证遗漏，需要建立固定路由。

## 与 project/rules 的关系

`project/rules/` 保存目标项目规则正文或导入索引；本目录只登记 AI-Teams 如何在任务中按需读取它们。
