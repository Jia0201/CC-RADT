# 索引说明

`index/` 目录提供 AI-Teams 的轻量导航、需求验收入口、文档关系图入口和 CodeGraph 状态入口。

索引只保存入口、路径、摘要、状态和跳转关系，不保存长内容，不替代正式知识库。

## 规则

非平凡任务必须先阅读 `index/INDEX.md`，再阅读相关索引文件，最后读取目标文件。能读摘要则不读全文；CodeGraph 可用时，Dev 和 QA 优先使用 CodeGraph。
