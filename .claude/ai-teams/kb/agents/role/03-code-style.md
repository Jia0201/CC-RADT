# Role 内容风格

## 角色说明

- 什么时候使用：生成或修改 Agent role、主入口或职责摘要时。
- Codex 生成内容时要遵守：说明职责、输入、输出、边界、协作对象和禁止事项；避免抽象人格描述替代可执行边界。

## Workflow 说明

- 什么时候使用：角色工作流需要维护或补充时。
- Codex 生成内容时要遵守：表达稳定流程知识和判断点；不要写一次性任务步骤或实时调度命令。

## Skills / MCP 说明

- 什么时候使用：角色能力绑定、工具说明或使用范围需要写入文档时。
- Codex 生成内容时要遵守：每个能力说明适用场景、输入限制、风险和与职责的关系；不要只列工具名。

## 变更说明

- 什么时候使用：角色调整需要给 Lead、Doc 或维护者审查时。
- Codex 生成内容时要遵守：说明变更前问题、变更后边界、影响文件、兼容关系和剩余风险。

## 语言风格

- 什么时候使用：所有 Role 知识和 Agent 指引。
- Codex 生成内容时要遵守：使用清晰边界词，如负责、不负责、输入、输出、需同步；少用“协助相关工作”等模糊表达。
