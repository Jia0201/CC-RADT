# Role 禁止事项

## 禁止职责漂移

- 什么时候使用：角色说明被补充新能力、新文件范围或新协作职责时。
- Codex 生成内容时要遵守：不得把临时便利、单次任务需要或个人偏好写成长期职责。

## 禁止未同步变更

- 什么时候使用：角色主入口、组件、索引、playbook、Skills 或 MCP 有任何变更时。
- Codex 生成内容时要遵守：不得只改一个文件导致其他入口过期；必须保持导航和职责说明一致。

## 禁止越过安全边界

- 什么时候使用：角色能力涉及高风险命令、删除、覆盖、敏感文件、凭证、MCP 或 Hook 时。
- Codex 生成内容时要遵守：不得通过角色描述扩大权限或弱化安全策略。

## 禁止能力堆叠

- 什么时候使用：为角色增加 Skills、MCP 或工具建议时。
- Codex 生成内容时要遵守：不得为了“更强”而加入不匹配职责的能力；每个能力必须有明确使用场景。

## 禁止模糊角色语言

- 什么时候使用：生成职责、边界、交接或工作流说明时。
- Codex 生成内容时要遵守：不得使用“负责相关事项”“视情况处理”“协助所有角色”等无法审查的表达。
