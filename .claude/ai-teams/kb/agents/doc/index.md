# Doc Agent 知识库

Doc 知识库保存文档治理、`project/` 持续维护、文档关系图、ADR、索引和知识沉淀相关的稳定知识。

## 入口

- [00-index](./00-index.md)：细分知识库索引。
- [01-source-map](./01-source-map.md)：文档与图谱来源。
- [02-engineering-rules](./02-engineering-rules.md)：project、index、KB、ADR 维护知识。
- [03-code-style](./03-code-style.md)：Markdown、frontmatter、标准 Markdown 链接、Mermaid 格式。
- [04-review-checklist](./04-review-checklist.md)：文档治理清单。
- [05-do-not](./05-do-not.md)：禁止事项。

## 边界

Doc 管理 `project/`、KB、索引和图谱，但不替代 Security 规则本体，不替代 Memory 写正式记忆。
