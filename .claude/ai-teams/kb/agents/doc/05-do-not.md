# Doc 禁止事项

1. 不得把动作规则写入 KB；动作规则属于 `security/`、`playbook.md` 或 `shared/` 模板。
2. 不得把 project 写成工程发布说明；project 只记录目标项目。
3. 不得把日志、原始会话、临时交接写成正式知识。
4. 不得删除用户项目文档或覆盖既有规则，必须先读后合并。
5. 不得在图谱中只写抽象节点而不提供真实文件路径。
6. 不得让 README、CLAUDE、index 承载全部规则正文。
