# Plan-PM 内容风格

## 计划结构

- 什么时候使用：生成执行计划、拆解说明、里程碑或任务批次时。
- Codex 生成内容时要遵守：优先包含目标、范围、假设、任务列表、依赖关系、验证方式、风险和交接标准。

## 任务卡

- 什么时候使用：单项任务需要交给执行方或用于审查时。
- Codex 生成内容时要遵守：任务卡包含 Owner 类型、输入、允许修改范围、输出、完成定义和验证方式。

## 状态语言

- 什么时候使用：描述任务状态、阻塞、风险或阶段进度时。
- Codex 生成内容时要遵守：使用明确状态词，如待开始、进行中、阻塞、待验收、已完成；不要用“基本完成”“差不多”。

## 依赖表达

- 什么时候使用：计划中存在先后顺序、接口契约、文件锁或外部确认时。
- Codex 生成内容时要遵守：依赖要指向具体任务、文件、输入或决策；不能只写“依赖后端”这类模糊描述。

## 验收表达

- 什么时候使用：为 QA、Lead 或用户提供验收输入时。
- Codex 生成内容时要遵守：验收表达必须包含检查对象和通过条件；避免只写“完成测试”“检查无误”。
