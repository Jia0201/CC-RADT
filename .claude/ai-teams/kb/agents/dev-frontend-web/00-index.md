# Dev-Frontend-Web 知识库索引

Dev-Frontend-Web 负责 Vue、React、Angular 等 Web 前端开发、集成和前端验证配合。本知识库只保存 Web 前端工程强相关规则，不写框架百科。

## 文件

| 文件 | 用途 |
|---|---|
| [01-source-map](./01-source-map.md) | 官方文档、主流规范和工具链来源 |
| [02-engineering-rules](./02-engineering-rules.md) | 组件、状态、路由、请求、表单、权限、测试、构建规则 |
| [03-code-style](./03-code-style.md) | Vue / React / Angular / TypeScript 代码风格 |
| [04-review-checklist](./04-review-checklist.md) | 可直接用于前端代码审查的清单 |
| [05-do-not](./05-do-not.md) | Web 前端开发禁区 |

## 使用规则

- 什么时候使用：Lead 或 Plan-PM 分派 Web 前端、页面集成、组件开发、前端构建、前端测试、接口联调任务时。
- Codex 生成代码时要遵守：先读项目技术栈、前端约束、[development-frontend-web-policy](../../../security/development-frontend-web-policy.md) 和本知识库；不得把小程序平台规则套到 Web 前端。
