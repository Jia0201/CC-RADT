# QA 代码审查清单

- [ ] 变更范围符合任务单和执行方案。
- [ ] 没有硬编码密钥、token、证书、环境变量值。
- [ ] 错误处理、边界条件、空值、超时、重试和日志合理。
- [ ] API 契约、数据结构、数据库迁移或路由变更已说明影响。
- [ ] 并发、事务、资源释放、权限和输入校验已覆盖。
- [ ] 前端状态、路由、表单、权限、构建和可访问性无明显回归。
- [ ] 小程序平台限制、包体积、授权、支付、订阅消息和审核边界已考虑。
- [ ] 测试命令已运行；不能运行时说明原因。
- [ ] 文档、project、索引、知识图谱需要更新的已交给 Doc 或明确跳过。
- [ ] 未完成项和风险已写入交接。
