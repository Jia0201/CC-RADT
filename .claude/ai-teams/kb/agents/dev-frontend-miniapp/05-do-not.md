# Dev-Frontend-Miniapp 禁止事项

## 敏感信息禁区

- 什么时候使用：任何小程序前端代码、配置、日志、构建产物和示例。
- Codex 生成代码时要遵守：不得把 `appsecret`、支付密钥、服务端 token、商户私钥、数据库连接、内部 API 密钥写入前端。

## 平台审核禁区

- 什么时候使用：授权、支付、订阅消息、分享、广告、隐私、用户资料任务。
- Codex 生成代码时要遵守：不得绕过平台审核限制；不得诱导授权；不得伪造用户同意、订阅或支付状态。

## 支付禁区

- 什么时候使用：支付下单、支付回调、订单状态、退款入口任务。
- Codex 生成代码时要遵守：不得在前端生成支付签名；不得由前端决定最终支付成功；不得跳过服务端校验。

## API 契约禁区

- 什么时候使用：服务端接口、登录流程、订单流程、用户信息流程变更任务。
- Codex 生成代码时要遵守：不得擅自改变 API 契约；必须同步服务端、文档、类型和测试。

## 错误处理禁区

- 什么时候使用：登录、授权、支付、订阅、分享、上传下载、网络请求任务。
- Codex 生成代码时要遵守：不得跳过错误处理；用户拒绝、超时、失败、异常都必须可恢复或可提示。

## 测试禁区

- 什么时候使用：新增平台能力或修复平台差异时。
- Codex 生成代码时要遵守：不得生成未测试代码后声称完成；不得只在一个平台验证却说多端通过。
