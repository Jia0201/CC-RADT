# Dev-Frontend-Miniapp 代码风格

## uni-app

- 什么时候使用：跨平台页面、组件、API 封装和条件编译任务。
- Codex 生成代码时要遵守：平台差异用条件编译隔离；公共逻辑抽到可复用模块；不得把条件编译写成难以维护的嵌套迷宫。

## 微信小程序

- 什么时候使用：WXML、WXSS、JS、JSON、微信 API、微信组件任务。
- Codex 生成代码时要遵守：页面结构、样式、逻辑、配置职责分离；异步 API 必须处理成功、失败和用户拒绝。

## 支付宝小程序

- 什么时候使用：AXML、ACSS、支付宝 API、支付宝组件任务。
- Codex 生成代码时要遵守：按支付宝 API 参数和错误码生成代码；不得照搬微信 `wx.*` 调用。

## 样式与布局

- 什么时候使用：响应式布局、rpx、暗色适配、组件样式、跨端样式任务。
- Codex 生成代码时要遵守：样式适配不同屏幕和安全区域；避免全局样式污染；不得用 Web 专属 CSS 能力假设所有平台支持。

## API 封装

- 什么时候使用：请求、上传下载、登录态刷新、错误处理、重试任务。
- Codex 生成代码时要遵守：统一封装请求、错误、超时、鉴权和日志；不得在页面中散落平台 API 调用和业务判断。

## 配置

- 什么时候使用：页面配置、分包配置、TabBar、权限声明、平台配置任务。
- Codex 生成代码时要遵守：配置变更必须说明影响范围；不得擅自改动平台审核敏感配置。
