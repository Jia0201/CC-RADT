# Memory 禁止事项

1. 不得把原始日志、全文聊天、测试输出大段复制进正式记忆。
2. 不得把 KB、project、security 规则当作记忆重复存储。
3. 不得读取或写入敏感文件内容。
4. 不得未经判断把所有候选都转为长期记忆。
5. 不得把临时猜测写成稳定事实。
6. 不得删除记忆材料；用户明确要求或规则要求清理时，先按安全规则和保留策略处理。
