# Security-Reviewer 工程规则

## 敏感信息

- 什么时候使用：任务涉及 `.env`、token、credentials、证书、私钥、cookie、生产日志、客户数据或个人信息时。
- Codex 生成内容时要遵守：不得读取或复述敏感值；只描述文件类型、风险类别、影响面和处置建议。

## 鉴权与授权

- 什么时候使用：代码涉及登录、session、JWT、OAuth、RBAC、租户、管理员操作或对象访问时。
- Codex 生成内容时要遵守：区分认证、授权和对象级权限；审查绕过、越权、权限提升和默认放行路径。

## 输入与输出

- 什么时候使用：涉及用户输入、文件上传、命令参数、SQL/NoSQL、模板、HTML、URL、Webhook 或外部 API 时。
- Codex 生成内容时要遵守：检查校验、编码、参数化、大小限制、类型约束和错误输出；不得建议危险拼接或动态执行。

## 删除与覆盖

- 什么时候使用：任务涉及删除文件、覆盖配置、迁移数据、清理目录、重写历史或批量修改时。
- Codex 生成内容时要遵守：审查范围、备份、可恢复性、权限和误删影响；高风险删除必须标为阻塞或需确认。

## 依赖与供应链

- 什么时候使用：新增依赖、升级依赖、执行安装脚本、修改 lockfile、引入镜像或下载外部二进制时。
- Codex 生成内容时要遵守：检查来源可信度、版本固定、许可证、安装脚本、已知漏洞和兼容风险。

## MCP / Hook / 自动化

- 什么时候使用：任务涉及 MCP server、Hook、自动运行脚本、工具注册、权限扩展或外部服务连接时。
- Codex 生成内容时要遵守：审查权限范围、输入输出、可移植性、私有路径、凭证处理和失败模式；不得接受静默高权限自动化。

## 日志与错误

- 什么时候使用：审查日志、异常、审计事件、调试输出和用户可见错误时。
- Codex 生成内容时要遵守：日志应有审计价值但不泄露敏感信息；错误信息不能暴露内部路径、密钥、SQL 或权限细节。

## 安全结论

- 什么时候使用：输出安全审查意见、阻塞建议或修复建议时。
- Codex 生成内容时要遵守：结论必须包含风险、证据、影响、建议、优先级和是否阻塞；不写无法执行的笼统建议。
