# Security-Reviewer 审查清单

## 敏感信息

- [ ] 是否读取、打印、提交或复制了 `.env`、token、credentials、证书、私钥或 cookie？
- [ ] 日志、错误、测试快照和文档是否泄露敏感值、内部路径或个人信息？
- [ ] 密钥处置是否包含撤销、轮换、历史清理或访问范围评估？

## 鉴权与权限

- [ ] 是否明确认证、授权、租户和对象级访问控制？
- [ ] 管理员、批量操作、导出、删除和支付等高风险路径是否有权限校验？
- [ ] 默认配置、异常分支和失败回退是否存在放行路径？

## 输入、输出与执行

- [ ] 用户输入、文件上传、URL、Webhook 和外部数据是否有校验和限制？
- [ ] SQL/命令/模板/HTML/路径是否避免危险拼接和动态执行？
- [ ] 错误响应是否避免暴露内部实现和敏感数据？

## 文件、数据与删除

- [ ] 删除、覆盖、迁移或批量修改是否限定范围且可恢复？
- [ ] 是否存在误删用户文件、项目文件、配置或历史数据的风险？
- [ ] 数据迁移是否说明回滚、备份和兼容性？

## 供应链与运行时

- [ ] 新依赖、镜像、二进制或脚本来源是否可信且版本明确？
- [ ] lockfile、安装脚本、postinstall、CI、Hook 和 MCP 是否有权限扩展风险？
- [ ] Docker/K8s/部署配置是否避免 root、明文 Secret 和过宽权限？

## 结论

- [ ] 审查意见是否包含风险、证据、影响、建议和是否阻塞？
- [ ] 修复建议是否具体、最小化且可验证？
- [ ] 未能确认的安全问题是否作为残余风险记录？
