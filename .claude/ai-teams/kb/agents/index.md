`agents/index.md` 是团队级 Agent 索引；单个 Agent 的 标准 Markdown 链接应落到主文件或组件文件，不再落到旧的单 Agent index 入口。

## 写入规则

- Agent 知识必须有来源和验证方式。
- 未验证内容先进入 `kb/candidates/`。
- 需要跨 Agent 复用的知识应沉淀到 [index](../shared/index.md)。
- 敏感信息不得写入知识库。
