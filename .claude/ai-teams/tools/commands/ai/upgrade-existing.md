# 外部升级器操作说明

## 用途

为已安装 CC-RADT 的项目提供外部升级操作说明。本指令不执行升级，不调用旧脚本或要求 Agent 同步文件，也不创建快照、运行日志或状态。

## 旧入口已停用

`tools/bin/ai-teams-upgrade.sh` 仅输出中文迁移说明。`--apply`、`--dry-run`、无参数及错误参数均以状态码 2 退出；单独 `--help`/`-h` 以 0 退出。所有调用均零写入，不再支持旧版“dry-run 先创建快照”的行为。不要用旧包里的脚本继续执行覆盖。

## 用户操作

1. 取得经验证的独立 CC-RADT 外部升级器，放在目标项目与 `.claude/ai-teams/` 之外；未交付或未经平台验收时只说明限制，不给出虚构下载地址。
2. 关闭目标项目的 Claude Code、Agent、Hook、观察台及后台写入任务，保留独立备份。不要在仍运行的 Harness 会话内申请 apply。
3. 在外部 UI/CLI 选择目标项目、可信旧基线和明确版本的新包；旧无清单公开包只能使用包外 sidecar，不修改旧附件。
4. 先只读预览，检查新增/更新/停用、保留数据、配置变化、冲突、系统版本、迁移路线及恢复位置。未知基线、同版本不同 build、缺迁移路线或冲突应停止处理。
5. 未签名清单默认只可预览。由用户亲自核对并明确输入或确认旧、新清单的完整 SHA-256 指纹，才允许申请 apply；生成清单或 `--seal` 不等于可信发布来源，Agent 不代为确认。
6. 由外部升级器在重新验证、独立备份和候选检查后执行事务。失败或中断按实际恢复状态处理，不能重新运行旧脚本补覆盖，也不能把关闭网页当成取消完成。
7. 只有外部升级器报告验证完成且无需恢复，才重新启动 Claude Code；旧原件和报告保留，由用户另行管理。

外部 CLI 参数以随独立程序提供的帮助为准。本说明不把开发原型、生成器测试或成功编译当作已支持实际跨版本升级的证明。

## 保护范围

- 系统版本是 `.claude/ai-teams/VERSION`；业务根 `VERSION`、README、源代码不覆盖。
- 项目资料、记忆、会话、共享运行状态、自装 Skills/MCP、用户 Agent 和提示词激活改动保留或显式报冲突。
- `memory/project/kb/shared` 不能按目录整体覆盖；未知文件默认数据，官方文件归属需可信旧清单证明。
- generated 索引/图谱首版没有智能合并；本地与新版同时修改时保守阻断，仅本地改而上游未变时保留。配置双方修改也不能假装已自动合并。
- `.claude/settings.local.json`、环境文件和密钥不纳入升级清单；CLAUDE.md 非受管区块不能覆盖。

## 输出与验证

本指令仅在当前响应说明入口、风险和待用户确认项，不修改项目文件。升级状态、报告、受保护原件和事务恢复由外部升级器提供；要求只读预览零写入、未授权 apply 被拒绝、数据守恒和恢复材料可验证。

权威边界见 [外部升级安全规则](../../../security/upgrade-policy.md)。
