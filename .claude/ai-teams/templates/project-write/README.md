# 项目文档写入模板

## 用途

用于更新项目画像、技术栈、命令、架构、依赖、验证和风险文档。

## 所有者

Lead、PD、Plan-PM 和 Doc 按文件所有权共同维护。

## 使用方式

复制 `template.md` 后填写写入目标、信息来源、更新原因、影响范围和验证方式。

## 输出

更新 `project/` 下对应文档，并在需要时同步 `index/PROJECT.md`。
