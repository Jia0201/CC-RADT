## 安全回归范围

- 未确认停止写入或未认可清单指纹，拒绝 apply。
- 本地新增内容、私有配置和业务文件不被目录覆盖；敏感路径不读入内容清单。
- JSON 重复键、未知迁移操作、缺少迁移路线、同名文件冲突和包篡改阻断。
- 系统文件新增、停用、权限单独变化均进入计划；VERSION 最后切换。
- 进程退出释放 OS 锁；未完成事务仍阻止下一次升级，路径大小写别名不创建第二把锁。
- 原件、候选和事务记录校验后才开始切换；记录大小超过读取上限时不移动原件。
- 记录/事件使用新建临时文件、fsync 和不覆盖发布；未发布残留不冒充有效事务。
- 事件采用递增序号和合法状态迁移，时钟回拨不能将完成事务变回可恢复状态。
- 中断恢复可重复；发现新内容或异常保留原件时停止，不能用恢复旧快照抹掉新工作。
- 故障注入使用返回式 failpoint 和独立子进程 `os.Exit(77)`；后者不会执行 defer 清理，不等同于物理断电。

## 未完成的发布门槛

1. **Windows 写入仍禁用。** 原生 NTFS DACL/SACL、备用数据流、目录持久化及写入者检查未完成，不能声称 Windows 已可无损升级。
2. **Linux 原生 ext4、macOS arm64、Windows 两架构验收未完成。** 构建或编译测试不代替目标设备运行。
3. **断电、磁盘故障与配额故障实机验证未完成。** 进程崩溃测试只证明对应程序中断边界；同卷原件不能替代异盘备份。
4. **发布者签名和升级器代码签名未配置。** Ed25519 验证代码已有测试；没有伪造官方签名、公钥或发布证书。
5. **未来跨大版本语义迁移未声明。** 引擎支持显式改名路线与缺路线阻断，但没有未经测试的 2.x 通用升级保证。
6. **智能图谱重建、复杂 Markdown 合并、执行中取消按钮不在首版实现。** 保守冲突阻断，不能宣称已经自动解决所有用户定制。
7. **真实业务项目没有写入验收。** 必须先在目标项目副本验证并保持维护窗口，不能用 fixture 成功替代所有项目验证。

## 复现

```sh
go test ./...
go test -race ./internal/engine ./internal/platform ./internal/web ./internal/release
go vet ./...
```

在仓库根运行 `tools/release/ai-teams-upgrade-manifest.test.mjs`；设置 `CC_RADT_UPDATER_BIN` 可启用两项 Go 联调。真实包测试入口是 `updater/integration/formal-smoke.mjs`，网页测试入口是 `updater/integration/ui-smoke.mjs`。开发测试需要 Node/Playwright；最终升级器不依赖它们。
