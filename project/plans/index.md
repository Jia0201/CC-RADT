# 项目计划索引

本目录由 Doc 维护项目索引，Plan-PM 提供目标项目执行计划、里程碑、依赖关系和多 Agent 分工。

## 使用规则

- 项目计划说明“为什么按这个顺序做”和“哪些任务有依赖”。
- 单次任务执行方案仍使用 `shared/tasks/EXECUTION_PLAN_TEMPLATE.md`。
- 跨 Owner、跨目录、多文件锁任务必须把锁范围和串并行边界写清楚。
- 计划变化影响项目状态、进度、风险或图谱时，Plan-PM 在交接中标明项目发现，由 Doc 合并到 `project/`。
