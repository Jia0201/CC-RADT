# 项目需求索引

本目录由 Doc 维护项目索引，PD 提供目标项目需求分析、业务边界、验收标准和待确认问题。

## 使用规则

- 需求必须区分已确认事实、待确认问题、建议方案和不可做范围。
- 需求不得替代任务单；任务执行仍使用 `shared/tasks/`。
- PD 开始需求分析前读取 `project/change-log.md`，只使用已经合入当前工作树的变化；远端待同步提交不得作为需求事实。
- 需求变更影响长期项目理解时，PD 在交接中标明项目发现，由 Doc 同步 `project/context.md`、`project/rules/index.md` 和 `project/graph.md`；Lead 关闭前检查是否已处理。
