# 记忆保留策略

## 保留

- 长期稳定的项目事实
- 稳定用户偏好
- 恢复信息
- 重要约束

## 优先保留

| 类别 | 示例 |
|---|---|
| 用户长期偏好 | 用户要求主工程优先、`.claude/` 只保留配置、暂不处理打包 |
| 稳定项目事实 | AI-Teams 根目录是工程大脑，Agent 本体在 `agents/` |
| 未完成恢复点 | 当前阶段、未完成项、下一步需要先读的文件 |
| 安全边界 | 不读取敏感文件内容、不自动删除用户项目文件 |
| 工具状态 | CodeGraph 已引入但运行态需检查 |
| 升级状态 | 已完成或待处理的工程结构迁移 |

## 不保留

- 原始日志
- 临时聊天内容
- 大段代码
- 敏感信息
- 未验证猜测

## 归档规则

- 被新记忆替代的旧事实进入 `memory/archive/`。
- 已完成且不再影响后续任务的恢复点进入 `memory/archive/`。
- 过期工具状态应保留最后一次验证日期，并在新验证后更新或归档。
- 归档不是删除；除非用户明确要求，不主动删除记忆文件。

## Agent 独立记忆边界

- Lead：调度偏好、用户长期决策边界、任务恢复状态。
- PD：需求解析口径、用户表达习惯、需求模板偏好。
- Plan-PM：计划拆解习惯、任务粒度、验收节奏。
- Dev：项目技术栈、规范、常用命令、容易踩坑的实现边界。
- QA：验证命令、回归范围、历史缺陷模式。
- Memory：记忆筛选策略、恢复点维护状态。
- Doc：知识库结构、标准 Markdown 规范、索引维护状态。
- Role：Agent 职责调整记录和边界变更。
- Security-Reviewer：敏感路径、安全例外、高风险操作约束。

## 复核周期

- 长期偏好：除非用户修改，默认持续有效。
- 项目事实：项目初始化、升级或架构变更后复核。
- 工具状态：每次相关任务前复核。
- 未完成恢复点：任务完成后归档或替换。
- 安全边界：默认长期有效，不因任务切换自动失效。
